# 🐾 X 桌宠 (X-Pet / CCbd)

## 🌟 核心特色

- **🌐 多平台社交广场支持（推特 · 币安广场 · OK星球）**：
  - **精准定位社交 Feed**：桌宠不仅支持 Twitter / X，还全面适配**币安广场 (Binance Square)** 与 **OK星球 (OKX Community/广场)** 这类类似推特的图文动态页面；
  - **完全不打扰专业交易**：采用智能路径与单页应用 (SPA) 路由感知，桌宠**绝不会**出现在 K 线盯盘、现货/合约交易等专业交易页面；
  - **独立站点开关**：在设置页面中，用户可自由独立勾选是否在「推特」、「币安广场」、「OK星球」中启用桌宠，多端状态互不干扰。
- **🐶 萌系多角色陪伴**：内置可爱泰迪犬、哈基米猫与小史莱姆，也可以随时上传你自己的角色头像或专属逐帧精灵图（Sprite Sheet）。
- **🎭 拟真生物节律与状态感知（告别抽搐动画）**：
  - **在用页面 (busy · 12fps)**：小动物专注地坐在电脑前码字工作，节奏舒缓专注；
  - **停下离开 (idle / sleepy · 8~9fps)**：当你停下操作或离开，它会从待机微呼吸自然过渡到深度打盹，告别旧版本 0.75s 快速抽搐；
  - **深夜哈欠 (yawn · 7fps)**：凌晨时段使用会打深沉的大哈欠（约 2.6s）提醒注意休息；
  - **点击互动 (poke · 13fps)**：戳戳它会有精确的单次起落弹性跳跃与暖心碎碎念；
  - **无损画质与接缝修复**：内置精灵图已全面完成循环尾帧光流无缝缝合与毛边噪点净化，并消除了外层机械拉伸造成的双重呼吸变形。
- **🏆 全新工位伴侣装备（Desk Gear）随经验解锁**：
  - 彻底重构原先遮挡头面部的 Emoji 装扮，并移除了已失效废弃的侧边道具选项；
  - 装备采用**纯矢量高清 SVG + 硬件加速微动效**，随桌宠尺寸等比缩放，优雅摆放在身前右下桌角：
    1. **🪑 极简工位**（0 XP）：纯净桌面，返璞归真；
    2. **☕ 暖心拿铁咖啡**（10 XP）：白瓷杯带爱心拉花，杯口升起缕缕白汽（`xpet-steam`）；
    3. **🐥 极客调试小黄鸭**（30 XP）：程序员解压神器，带轻微 Q 弹摇摆（`xpet-duck-wobble`）；
    4. **🪴 治愈多肉绿植**（70 XP）：双色饱满多肉陶瓷小盆栽；
    5. **💻 赛博霓虹电竞本**（140 XP）：微缩外星人风电竞本，带渐变霓虹 RGB 流光呼吸（`xpet-cyber-pulse`）；
    6. **🖥️ 复古大头电脑**（220 XP）：经典米白 80 年代 Macintosh/CRT 大头机，荧光绿命令行光标闪烁（`xpet-crt-blink`）；
    7. **🏆 专注大师金奖杯**（300 XP）：满级专注成就勋章，顶端星芒微微闪烁（`xpet-gold-shine`）。
  - *老用户历史装扮自动无损平滑迁移，无需手动重新配置。*
- **⏱️ 健康防沉迷与正向激励（经验系统）**：
  - 自定义每天的健康浏览时间区间（例如每天 30–90 分钟）；
  - **不催促、不评判**：在区间内停留可获得满额经验值；超过上限后经验逐步递减，绝不扣减已有经验；
  - 每日自动结算经验，累计经验自动解锁工位装备与成长故事（无需繁琐打卡领取）。
- **📖 宠物的小本子（31 页成长记录）**：
  - 随着累计陪伴天数与达标天数增长，自动解锁一页页细腻温暖的陪伴小故事与台词。
- **📊 行为统计与月度日历**：
  - 自动记录发帖、点赞、收藏、转发、关注次数、在线时长以及屏幕滚动总距离（按米折算）；
  - 优雅的月度日历视图与数据统计，支持数据一键导出备份与恢复。
- **🎉 节日与时段问候**：
  - 支持阳历、农历节日（除夕、春节、元宵、端午、中秋、圣诞等）与自定义纪念日当天专属问候；
  - 凌晨、早上、中午、晚间自定义时段问候语。
- **🔒 100% 纯本地与隐私安全**：
  - 所有数据全部保存在本地浏览器 `chrome.storage.local`；
  - 没有任何网络上报，不需要注册登录，无外部追踪器。

## 🚀 安装与使用指南

本项目为标准 Chrome Extension（Manifest V3），适用于 Google Chrome、Microsoft Edge、Brave 等所有主流 Chromium 内核浏览器。

### 1. 下载项目
克隆本仓库到本地，或者下载 ZIP 包解压：
```bash
git clone https://github.com/laochenjames/CCbd.git
```

### 2. 加载到浏览器
1. 打开浏览器，在地址栏输入：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. 打开右上角的 **「开发者模式」 (Developer mode)** 开关；
3. 点击左上角的 **「加载已解压的扩展程序」 (Load unpacked)**；
4. 选择本项目所在的主文件夹（即包含 `manifest.json` 的 `CCbd` 根目录）。

### 3. 开始陪伴
- 打开 **[x.com](https://x.com)**、**[币安广场](https://www.binance.com/zh-CN/square)** 或 **[OK星球](https://www.okx.com/zh-hans/square)** 动态页面；
- 右下角即可看到常驻的可爱桌宠与工位桌搭！
- **鼠标左键拖动**：可将宠物移动到屏幕任意位置（位置会自动记忆）；
- **鼠标左键点击**：戳一戳互动，宠物会有轻快的弹性跳跃、清脆的“啵啵”气泡音，并弹出当前状态台词；
- **鼠标右键点击**：唤出功能菜单，可一键切换角色、更换工位装备、查看「今日小结」、暂时隐藏或打开设置页；
- **键盘快捷键**：随时按下 <kbd>Alt + P</kbd> 可快速隐身/呼回桌宠（可在设置页开关）。

## 🎨 自定义精灵图（动画制作）

除了使用内置的泰迪犬与哈基米猫，你还可以在**设置页**为任意角色上传自定义动画精灵图：

1. **精灵图格式要求**：
   - 一张横向等间距拼合的多帧长图（PNG 或 WebP 格式，需透明背景）；
   - 总帧宽 = 单帧宽 × 帧数（单帧高度建议不超过 320px）；
2. **支持的状态动作**：
   - `idle`：待机微呼吸（默认基础图）；
   - `busy`：你在操作页面时（专注工作）；
   - `sleepy`：停下无操作时（打盹入睡）；
   - `yawn`：深夜时段（打哈欠）；
   - `poke`：被点击时（受击/跳跃反馈）；
3. **推荐帧率设定**：
   - 待机 `idle`: 8~9 fps（约 2.0s 舒缓微呼吸）
   - 工作 `busy`: 12 fps（约 1.5s 专注节奏）
   - 哈欠 `yawn`: 7 fps（约 2.5s 真实困倦哈欠）
   - 打盹 `sleepy`: 8~10 fps（约 2.5~3.0s 深沉入睡）
   - 点击 `poke`: 12~14 fps（约 1.3s 单次弹性起落）

> 本项目 `tools/` 目录中提供了制作与优化精灵图的 Python 辅助工具（包含关键帧提取、接缝无缝缓动闭合等）。本地可双击打开 `preview_test.html` 实时对比查看各动作节奏。

## 🛠️ 开源二次开发与深度定制指南

如果你想基于本项目进行二次开发，以下是关键架构切入点：

### 1. 适配其他网站（不仅限 X / Twitter）
目前扩展默认在 X 页面运行，若想让桌宠在全网或特定网站（如 Bilibili、YouTube、Reddit、GitHub）运行：
- 修改 `manifest.json` 中的 `content_scripts.matches`，例如改为 `<all_urls>`；
- 修改 `content.js` 中的 `SELECTORS` 对象，配置目标网站的点赞、发送、收藏等 DOM 选择器即可捕获交互事件。

### 2. 添加全新的工位装备或不同电脑款式
- **数据声明**：在 `shared.js` 的 `XPET.ACCESSORIES` 中加入新道具 ID、名称、解锁所需经验 `need` 与描述；
- **SVG 矢量绘制**：在 `content.js` 的 `GEAR_SVGS` 字典中添加对应的高清 SVG 矢量结构；
- **专属动效**：在 `pet.css` 中为 `.xpet-gear-<你的道具ID>` 编写 CSS keyframes 动效（如光效、浮动、晃动等）。

### 3. 添加全新内置角色
- 在 `shared.js` 的 `BUILTIN_SPRITES` 中声明角色键名与动画帧信息；
- 将切好的 WebP 动画放入 `sprites/<角色名>/` 目录并在 `manifest.json` 的 `web_accessible_resources` 中暴露；
- 在 `shared.js` 的 `builtinChar()` 中注册角色展示名称。

### 4. 扩充小本子故事
- 故事定义位于 `stories.js` 的 `XPET.STORIES` 数组，支持占位符 `{days}` `{full}` `{total}`。

## 📁 目录结构

```text
├── manifest.json         # 扩展配置文件 (Manifest V3)
├── background.js        # 后台 Service Worker（辅助打开设置页）
├── content.js           # 内容脚本（交互监听、计时、动画驱动、工位装备渲染）
├── shared.js            # 公共配置、台词、经验算法、装备数据与状态机核心
├── stories.js           # 31 页成长记录故事文本
├── pet.css              # 宠物渲染、硬件加速动画、工位装备动效与气泡样式
├── options.html/css/js  # 设置面板（角色编辑、日历、工位装备选择、备份导入导出等）
├── preview_test.html    # 本地动效对比与工位装备实时预览页面
├── sprites/             # 内置精灵图动画资源 (WebP)
│   ├── cat/             # 哈基米猫 (idle, busy, sleepy, yawn, poke)
│   └── teddy/           # 泰迪犬 (idle, busy, sleepy, yawn, poke)
└── tools/               # 精灵图自动化构建与切帧工具脚本
```
