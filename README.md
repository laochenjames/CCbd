# 🐾 X 桌宠 (X-Pet)

> 一只安安静静陪你逛推特的卡通桌面小伙伴。陪伴、防沉迷、时间管理与趣味互动，支持完全自定义角色与动画。

## 🌟 核心特色

- **🐶 萌系多角色陪伴**：内置可爱泰迪犬、哈基米猫与小史莱姆，也可以随时上传你自己的角色头像或专属逐帧精灵图（Sprite Sheet）。
- **🎭 拟真行为与状态感知**：
  - **在用页面 (busy)**：小动物专注地坐在电脑前/翻书/看手机；
  - **停下离开 (idle / sleepy)**：当你停下操作或离开，它会趴下进入舒缓打盹状态；
  - **深夜哈欠 (yawn)**：凌晨时段使用会打深沉的大哈欠提醒注意休息；
  - **点击互动 (poke)**：戳戳它会有生动的弹性受击跳跃与暖心碎碎念。
- **⏱️ 健康防沉迷与正向激励（经验系统）**：
  - 自定义每天的健康浏览时间区间（例如每天 30–90 分钟）；
  - **不催促、不评判**：在区间内停留可获得满额经验值；超过上限后经验逐步递减，绝不扣减已有经验；
  - 每日自动结算经验，累计经验可线性解锁精美装扮（🎀蝴蝶结、🧢小帽子、🕶️墨镜、🌸小花、👑皇冠等，无需繁琐打卡领取）。
- **📖 宠物的小本子（31 页成长记录）**：
  - 随着累计陪伴天数与达标天数增长，自动解锁一页页细腻温暖的陪伴小故事与台词。
- **📊 行为统计与月度日历**：
  - 自动记录发推、点赞、收藏、转发、关注次数、在线时长以及屏幕滚动总距离（按米折算）；
  - 优雅的月度日历视图与数据统计，支持数据一键导出备份与恢复。
- **🎉 节日与时段问候**：
  - 支持阳历、农历节日（除夕、春节、元宵、端午、中秋、圣诞等）与自定义纪念日当天专属问候；
  - 凌晨、早上、中午、晚间自定义时段问候语。
- **🔒 100% 纯本地与隐私安全**：
  - 所有数据全部保存在本地浏览器 `chrome.storage.local`；
  - 没有任何网络上报，不需要注册登录，无外部追踪器。

## 🚀 安装与使用指南

本项目为标准 Chrome Extension（Manifest V3），适用于 Google Chrome、Microsoft Edge、Brave 等所有主流 Chromium 内核浏览器。

### 1. 下载项目
克隆本仓库到本地，或者下载 ZIP 包解压：
```bash
git clone https://github.com/your-username/x-pet.git
```

### 2. 加载到浏览器
1. 打开浏览器，在地址栏输入：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. 打开右上角的 **「开发者模式」 (Developer mode)** 开关；
3. 点击左上角的 **「加载已解压的扩展程序」 (Load unpacked)**；
4. 选择本项目所在的主文件夹（包含 `manifest.json` 的目录）。

### 3. 开始陪伴
- 打开 [x.com](https://x.com) 或 [twitter.com](https://twitter.com)；
- 右下角即可看到常驻的可爱桌宠！
- **鼠标左键拖动**：可将宠物移动到屏幕任意位置（位置会自动记忆）；
- **鼠标左键点击**：戳一戳互动，宠物会跳跃并显示气泡台词与今日简要数据；
- **鼠标右键点击**：唤出功能菜单，可一键切换角色、查看「今日小结」或打开设置页。

## 🎨 自定义精灵图（动画制作）

除了使用内置的泰迪犬与哈基米猫，你还可以在**设置页**为任意角色上传自定义动画精灵图：

1. **精灵图格式要求**：
   - 一张横向等间距拼合的多帧长图（PNG 或 WebP 格式，需透明背景）；
   - 总帧宽 = 单帧宽 × 帧数（单帧高度建议不超过 320px）；
2. **支持的状态动作**：
   - `idle`：待机微呼吸（默认基础图）；
   - `busy`：你在操作页面时（拿着道具/工作）；
   - `sleepy`：停下无操作时（打盹入睡）；
   - `yawn`：深夜时段（打哈欠）；
   - `poke`：被点击时（受击/跳跃反馈）；
3. **推荐帧率设定**：
   - 待机 `idle`: 8~9 fps（约 2.0s 舒缓微呼吸）
   - 工作 `busy`: 12 fps（约 1.5s 专注节奏）
   - 哈欠 `yawn`: 7 fps（约 2.5s 真实困倦哈欠）
   - 打盹 `sleepy`: 8~10 fps（约 2.5~3.0s 深沉入睡）
   - 点击 `poke`: 12~14 fps（约 1.3s 单次弹性起落）

> 本项目 `tools/` 目录中提供了制作与优化精灵图的 Python 辅助工具（包含关键帧提取、接缝无缝缓动闭合等）。

## 📁 目录结构

```text
├── manifest.json         # 扩展配置文件 (Manifest V3)
├── background.js        # 后台 Service Worker（辅助打开设置页）
├── content.js           # 内容脚本（注入 X 页面，实现宠物交互、计时、统计等）
├── shared.js            # 公共配置、台词、经验计算与状态机逻辑
├── stories.js           # 31 页成长记录故事文本
├── pet.css              # 宠物渲染、硬件加速动画与气泡样式
├── options.html/css/js  # 设置面板（角色编辑、日历、小本子、备份导入导出等）
├── preview_test.html    # 本地动效对比与测试页面
├── sprites/             # 内置精灵图动画资源 (WebP)
│   ├── cat/             # 哈基米猫 (idle, busy, sleepy, yawn, poke)
│   └── teddy/           # 泰迪犬 (idle, busy, sleepy, yawn, poke)
└── tools/               # 精灵图自动化构建与切帧工具脚本
```
