# 🐾 CCbd 伴宠 (CCbd)

> 一只陪你逛推特、币安广场、OK星球的卡通伴宠，是你在屏幕里的「嘴替」：在你发帖、点赞、深夜还没睡的时候，用第一人称说出你可能在想的话。不劝导、不催促、不评判。

## 🌟 核心特色

- **🌐 多平台社交广场支持（推特 · 币安广场 · OK星球）**：
  - **精准定位社交 Feed**：伴宠不仅支持 Twitter / X，还全面适配**币安广场 (Binance Square)** 与 **OK星球 (OKX Orbit/社区)** 这类类似推特的图文动态页面；
  - **完全不打扰专业交易**：采用智能路径与单页应用 (SPA) 路由感知，伴宠**绝不会**出现在 K 线盯盘、现货/合约交易等专业交易页面（脚本在这些站点的所有页面都会加载，但交易、资产等页面一律不显示、不计时、不读取内容）；
  - **右上角快捷图标开关**：点击浏览器右上角插件图标即可弹出控制面板，独立勾选开启/关闭「推特」、「币安广场」、「OK星球」，并支持一键刷新当前页。
- **🧸 分层静态图陪伴与自定义角色**：内置小桌宠 CICI（状态整图 + 独立眼睛层，工作/发呆/睡着/伸懒腰/喝水 5 种姿态，眼睛随时段和状态变化并自动眨眼；其他内置角色暂时移除），也可以随时上传你自己的角色头像或专属逐帧精灵图（Sprite Sheet）；显示大小分「标准 / 大 / 特大」三档。
- **🤖 AI 角色与台词一键生成 / 导入（告别繁琐逐条配置）**：
  - **标准化 Prompt 模板**：内置 Web3 Degen 交易员、傲娇吐槽猫咪、元气忠诚柴柴、毒舌打工人、温柔治愈系等多款人设灵感，支持自定义个性化需求；
  - **跨模型无缝协作**：一键生成高质量标准化 Prompt，复制发送给任意大模型（ChatGPT、Claude、DeepSeek、Kimi、豆包等）；
  - **智能解析与语气过滤**：直接粘贴 AI 回复（支持自动清洗 Markdown 代码块、末尾逗号，并按第一人称嘴替规范自动过滤含第二人称或说教的违规句），一键完成 15 类动作全套台词和每日时段问候的极速导入。
- **🎭 拟真生物节律与状态感知（告别抽搐动画）**：
  - **在用页面 (busy · 12fps)**：小动物专注地坐在电脑前码字工作，节奏舒缓专注；
  - **停下离开 (idle / sleepy · 8~9fps)**：当你停下操作或离开，它会从待机微呼吸自然过渡到深度打盹，告别旧版本 0.75s 快速抽搐；
  - **深夜哈欠 (yawn · 7fps)**：深夜时段使用时，约每 20 分钟打一次深沉的大哈欠（约 2.6s，只演一遍），其余时间维持工作姿态，不会整晚循环；
  - **点击互动 (poke · 13fps)**：戳戳它会有精确的单次起落弹性跳跃与暖心碎碎念；
  - **无损画质与接缝修复**：内置精灵图已全面完成循环尾帧光流无缝缝合与毛边噪点净化，并消除了外层机械拉伸造成的双重呼吸变形。
- **🏆 工位伴侣装备（Desk Gear）随陪伴天数解锁**：
  - 彻底重构原先遮挡头面部的 Emoji 装扮，并移除了已失效废弃的侧边道具选项；
  - 装备采用**纯矢量高清 SVG + 硬件加速微动效**，随伴宠尺寸等比缩放，优雅摆放在身前右下桌角：
    1. **🪑 极简工位**（0 天）：纯净桌面，返璞归真；
    2. **☕ 暖心拿铁咖啡**（陪伴 3 天）：白瓷杯带爱心拉花，杯口升起缕缕白汽（`xpet-steam`）；
    3. **🐥 极客调试小黄鸭**（陪伴 7 天）：程序员解压神器，带轻微 Q 弹摇摆（`xpet-duck-wobble`）；
    4. **🪴 治愈多肉绿植**（陪伴 14 天）：双色饱满多肉陶瓷小盆栽；
    5. **💻 赛博霓虹电竞本**（陪伴 30 天）：微缩外星人风电竞本，带渐变霓虹 RGB 流光呼吸（`xpet-cyber-pulse`）；
    6. **🖥️ 复古大头电脑**（陪伴 60 天）：经典米白 80 年代 Macintosh/CRT 大头机，荧光绿命令行光标闪烁（`xpet-crt-blink`）；
    7. **🏆 陪伴纪念小奖杯**（陪伴 100 天）：一起过了好些天的小纪念，顶端星芒微微闪烁（`xpet-gold-shine`）。
  - *老用户历史装扮自动无损平滑迁移，无需手动重新配置。*
- **🖼️ 手绘质感背景场景（Scene Layers · v0.13.0 新增）**：
  - 在小桌宠身后增加了一层精美的手绘质感圆形窗景，让伴宠从单纯的浮动贴纸变成坐在一个小场景里工作；
  - 提供 7 款精巧场景（雨天、清晨晴空、午后暖光、黄昏晚霞、夜晚星空、春日微风、冬日初雪），支持**跟随时段自动切换**或**手动固定**，并支持右键菜单二级自适应菜单快捷切换；
  - 角色容器自动叠加环境氛围微调滤镜（≤12%），且带轻微呼吸浮动；
  - 原矢量小物件桌搭已优雅软关闭，整体界面更加协调治愈。
- **⏱️ 陪伴而不管控（贴合你，不校准你）**：
  - 伴宠不设每日上限、不催你休息、不报时长；时长统计只在「今日统计」和设置页日历里主动查看；
  - 只在你发帖、转发、关注、点赞（概率很低）、深夜还在用的时候，用第一人称说一句“心里话”，如「我考虑考虑要不要睡觉」，不劝导；点一下它，它会说自己在干嘛（「我也在刷推特」）；
  - 同一时刻只说一句，低优先级的话不会打断高优先级的话；宠物被隐藏或标签页不在前台时，问候、纪念、日记这类一次性通知不会被白白用掉。
- **📖 宠物的日记（12 页）**：
  - 随着累计陪伴天数（不要求连续）增长，自动解锁一页页宠物自己的日记：写它的日子，而不是对你的评价。
- **📊 双层行为统计与月度日历（总数合并 + 各站单独明细）**：
  - **全网总计**：自动汇总在各站的发帖、点赞、收藏、转发、关注次数、在线时长以及屏幕滚动总距离；
  - **分站独立明细**：在「今日小结」、右上角快捷弹窗以及设置页日历中，清晰展现推特、币安广场、OK星球各自的时长与交互数据；
  - 优雅的月度日历视图与数据统计，支持数据一键导出备份与恢复。
- **🎉 节日与时段问候**：
  - 支持阳历、农历节日（除夕、春节、元宵、端午、中秋、圣诞等）与自定义纪念日当天专属问候；
  - 凌晨、早上、中午、晚间自定义时段问候语。
- **🔒 100% 纯本地与隐私安全**：
  - 所有数据全部保存在本地浏览器 `chrome.storage.local`；
  - 没有任何网络上报，不需要注册登录，无外部追踪器。

## 🚀 安装与使用指南

本项目为标准 Chrome Extension（Manifest V3），适用于 Google Chrome、Microsoft Edge、Brave 等所有主流 Chromium 内核浏览器。

### 1. 下载项目
克隆本仓库到本地，或者下载 ZIP 包解压：
```bash
git clone https://github.com/laochenjames/CCbd.git
```

### 2. 加载到浏览器
1. 打开浏览器，在地址栏输入：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. 打开右上角的 **「开发者模式」 (Developer mode)** 开关；
3. 点击左上角的 **「加载已解压的扩展程序」 (Load unpacked)**；
4. 选择本项目所在的主文件夹（即包含 `manifest.json` 的 `CCbd` 根目录）。

### 3. 开始陪伴
- 打开 **[x.com](https://x.com)**、**[币安广场](https://www.binance.com/zh-CN/square)** 或 **[OK星球](https://www.okx.com/zh-hans/orbit)** 动态页面；
- 右下角即可看到常驻的可爱伴宠与工位桌搭！
- **鼠标左键拖动**：可将宠物移动到屏幕任意位置（按各站点独立记忆位置）；
- **鼠标左键点击**：点一下互动，宠物会有克制的微弹反馈并弹出当前状态台词（如「我也在刷推特」；可在设置页开启轻柔的 Web Audio 气泡音效，默认关闭）；
- **鼠标右键点击**：唤出功能菜单，可一键切换角色、查看「今日小结」与「今日统计」、开启「今天安静（只保留动画）」、暂时隐藏或打开设置页；
- **键盘快捷键**：随时按下 <kbd>Alt + P</kbd> 可快速隐身/呼回伴宠（可在设置页开关）。

## ⚙️ 开放给用户的自定义设置

在扩展设置页面中，用户可随时定制以下功能，全部修改**实时生效且支持完整导入/导出备份**：

| 设置项 | 可配置内容 | 说明 |
|---|---|---|
| **生效站点** | 推特 (X)、币安广场 (Binance Square)、OK星球 (OKX Orbit) | 用户可在右上角图标或设置页独立勾选开关各平台，仅在社交广场生效，不打扰专业交易盯盘（X 的私信与设置页亦自动排除） |
| **角色与形象** | 角色名称、内置形象 (小桌宠 CICI)、头像上传、显示大小 (标准/大/特大) | 支持上传逐帧精灵图与单帧图片 |
| **工位伴侣装备** | 极简工位、拿铁咖啡、小黄鸭、多肉、电竞本、复古大头电脑、金奖杯 | 摆在宠物身前桌角，随累计陪伴天数自动解锁，带专属动态视觉效果 |
| **外观与交互偏好** | 伴宠静止不透明度 (30%~100%)、台词气泡停留时长 (1.0s~8.0s，默认预设 1.5s~6.0s)、点击气泡微音效 (默认关闭)、<kbd>Alt+P</kbd> 快捷键显隐 | 平时半透明不遮挡网页内容，鼠标悬停或拖动时自动恢复 100% |
| **个性化台词** | 点击（含分站）、发推/发帖、点赞、收藏、转发、关注、深夜、回来等 15 种场景 | 一行一句，支持 `{n}` `{stats}` `{days}` 等占位符 |
| **伴宠画像** | 作息（夜猫子/普通/早睡）、话多话少、语气（懒散/俏皮） | 选择题，不用写台词；语气可一键套到当前角色 |
| **今天安静** | 右键菜单或右上角弹窗一键开启「今天安静」 | 当天 24:00 前除主动点击外不弹任何气泡，只安静保留动画陪伴 |
| **深夜与回来** | 深夜时段（可关）、离开后回来的一句话、陪伴天数纪念 | 自定义时间窗口，支持跨午夜设定 |
| **时段与节日问候** | 凌晨/早/中/晚时段范围与问候台词、阳历/农历/除夕节日祝福 | 支持用户无限增删自定义纪念日 |

## 🎨 自定义精灵图（动画制作）

除了使用内置的泰迪犬、哈基米猫、柴犬与佩佩蛙，你还可以在**设置页**为任意角色上传自定义动画精灵图：

1. **精灵图格式要求**：
   - 一张横向等间距拼合的多帧长图（PNG 或 WebP 格式，需透明背景）；
   - 总帧宽 = 单帧宽 × 帧数（单帧高度建议不超过 320px）；
2. **支持的状态动作**：
   - `idle`：待机微呼吸（默认基础图）；
   - `busy`：你在操作页面时（专注工作）；
   - `sleepy`：停下无操作时（打盹入睡）；
   - `yawn`：深夜时段（打哈欠）；
   - `poke`：被点击时（受击/跳跃反馈）；
3. **推荐帧率设定**：
   - 待机 `idle`: 8~9 fps（约 2.0s 舒缓微呼吸）
   - 工作 `busy`: 12 fps（约 1.5s 专注节奏）
   - 哈欠 `yawn`: 7 fps（约 2.5s 真实困倦哈欠）
   - 打盹 `sleepy`: 8~10 fps（约 2.5~3.0s 深沉入睡）
   - 点击 `poke`: 12~14 fps（约 1.3s 单次弹性起落）

> 本项目 `tools/` 目录中提供了制作与优化精灵图的 Python 辅助工具（包含关键帧提取、接缝无缝缓动闭合等）。本地可双击打开 `preview_test.html` 实时对比查看各动作节奏。

## 🛠️ 开源二次开发与深度定制指南

如果你想基于本项目进行二次开发，以下是关键架构切入点：

### 1. 适配其他网站（不仅限 X / Twitter）
目前扩展默认在 X、币安广场、OK星球运行，若想让伴宠在全网或特定网站（如 Bilibili、YouTube、Reddit、GitHub）运行：
- 修改 `manifest.json` 中的 `content_scripts.matches`，例如改为 `<all_urls>`；
- 修改 `content.js` 中的 `SELECTORS` 对象，配置目标网站的点赞、发送、收藏等 DOM 选择器即可捕获交互事件。

### 2. 添加全新的工位装备或不同电脑款式
- **数据声明**：在 `shared.js` 的 `XPET.ACCESSORIES` 中加入新道具 ID、名称、解锁所需累计陪伴天数 `need` 与描述；
- **SVG 矢量绘制**：在 `content.js` 的 `GEAR_SVGS` 字典中添加对应的高清 SVG 矢量结构；
- **专属动效**：在 `pet.css` 中为 `.xpet-gear-<你的道具ID>` 编写 CSS keyframes 动效（如光效、浮动、晃动等）。

### 3. 添加全新内置角色
- 在 `shared.js` 的 `BUILTIN_SPRITES` 中声明角色键名与动画帧信息；
- 将切好的 WebP 动画放入 `sprites/<角色名>/` 目录并在 `manifest.json` 的 `web_accessible_resources` 中暴露；
- 在 `shared.js` 的 `builtinChar()` 中注册角色展示名称。

### 4. 扩充宠物日记
- 故事定义位于 `stories.js` 的 `XPET.STORIES` 数组，支持占位符 `{days}`。

## 📁 目录结构

```text
├── manifest.json         # 扩展配置文件 (Manifest V3)
├── background.js        # 后台 Service Worker（辅助打开设置页）
├── content.js           # 内容脚本（交互监听、计时、动画驱动、工位装备渲染）
├── shared.js            # 公共配置、台词、装备数据、站点规则与语气校验核心
├── stories.js           # 12 页宠物日记
├── pet.css              # 宠物渲染、硬件加速动画、工位装备动效与气泡样式
├── popup.html/css/js    # 浏览器右上角快捷开关与今日陪伴统计弹窗
├── options.html/css/js  # 设置面板（角色编辑、AI 导入、日历、工位装备选择、备份导入导出等）
├── HANDOFF.md           # 产品定位、语气规范与技术架构交接文档
├── CHANGELOG.md         # 版本演进记录
├── PRIVACY.md           # 隐私政策说明（中英双语）
├── preview_test.html    # 本地动效对比与工位装备实时预览页面
├── sprites/             # 内置精灵图动画资源 (WebP)
│   ├── teddy/           # 泰迪犬（暂时移除，不打包；idle, busy, sleepy, yawn, poke）
│   ├── cat/             # 哈基米猫（暂时移除，不打包）
│   ├── doge/            # 柴犬（暂时移除，不打包）
│   ├── pepe/            # 佩佩蛙（暂时移除，不打包）
│   └── chabit/          # 小桌宠 CICI（分层静态图：5 张状态整图 + 4 张眼睛层 eye_*）
└── tools/               # 精灵图切帧、语气扫描 (lint_tone.js)、站点测试 (test_site_rules.js) 与打包脚本
```
